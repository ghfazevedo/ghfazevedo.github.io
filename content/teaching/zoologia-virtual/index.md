*Zoologia Virtual* is an interactive teaching resource on invertebrate zoology, produced for Zoology classes at the Universidade Federal de Minas Gerais with support from the Programa Especial de Graduação (PEG, Pró-Reitoria de Graduação). It was originally intended to be distributed on CD-ROM as a Windows program built in Macromedia Flash. Flash no longer runs in modern browsers, so the original program is shown here through [Ruffle](https://ruffle.rs), an open-source Flash emulator. The content is unchanged and is in Portuguese. Only Arthropda, Cnidaria and Porifera are completed and working.

> [!NOTE] 
>It might not work well on your phone since it was designed for computers.

The program's own exit button and full-screen mode do nothing in the browser; use the **Full screen** button below the player instead. The original Windows executable is available from the [VirtualZoology repository](https://github.com/ghfazevedo/VirtualZoology).
